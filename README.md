# Auto-ZTyper
### Video demo: 
### Uses easyOCR to find incoming words and automatically types the words for you using PyAutoGUI in ZType.

**Use 1920x1080**
After running the code wait until the terminal prints "Ready"
Go to zty.pe and press the 'W' key.

This uses PyAutoGUI to take screenshots of the upper region of the screen. The screenshots then gets read by easyOCR and it will sort it in an array. PyAutoGUI then types out the words inside the array.
